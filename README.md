# .github

The org profile for [`frompt`](https://github.com/frompt-org). [`profile/README.md`](profile/README.md)
renders at `github.com/frompt-org` **once this repository is public** — GitHub reads an org's
profile only from a public `.github` repo, so while private the page exists and does not
display. It is a pointer; the homepage is [`frompt-org/frompt`](https://github.com/frompt-org/frompt).
