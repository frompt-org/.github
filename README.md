# .github

The org profile for [`frompt-org`](https://github.com/frompt-org). [`profile/README.md`](profile/README.md)
is what renders at `github.com/frompt-org` — GitHub reads an org's profile only from a public
`.github` repository, and this one is public. It is a pointer; the homepage is
[`frompt-org/frompt`](https://github.com/frompt-org/frompt).
